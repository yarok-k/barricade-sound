# Barricade Sound

Окно управления звуком для barricade-bar на Rust, GTK 3 и Layer Shell (Wayland).

## Описание

Barricade Sound — это лёгкое всплывающее окно в правом верхнем углу экрана, позволяющее управлять звуком, не выходя из бара. Приложение использует:
- **GTK 3** и **gtk-layer-shell** для отрисовки overlay-окна в Wayland-сессиях
- **wpctl** (WirePlumber / PipeWire) для управления громкостью, mute и устройствами
- **playerctl** (MPRIS) для управления медиаплеером
- **Rust** для обеспечения производительности и безопасности памяти

## Возможности

- Громкость, mute и выбор устройства вывода по умолчанию
- Усиление, mute и выбор устройства ввода (микрофона) по умолчанию
- Управление плеером: назад / пауза-воспроизведение / вперёд
- Ползунок перемотки с отображением прошедшего и общего времени
- Обложка альбома (локальные файлы и удалённые URL с кэшированием)
- Собственные стили через CSS-файл
- Закрытие по `Esc` или при потере фокуса окна

## Установка

### Требования

- Rust 1.85+ (edition 2024)
- GTK 3.x
- GTK Layer Shell 0.7+
- Wayland-композитор с поддержкой `wlr-layer-shell`
- Утилиты времени выполнения: `wpctl` (WirePlumber), `playerctl`, `curl`

### Nix Users

Для воспроизводимого окружения разработки используется `shell.nix`:

```bash
nix-shell
```

Shell предоставляет все зависимости: GTK 3, cairo, pango, gdk-pixbuf, gtk-layer-shell, playerctl и инструменты сборки.

### Сборка

```bash
cargo build --release
```

### Запуск

```bash
cargo run --release
```

## Использование

Запустите бинарник (например, привяжите его к кнопке в barricade-bar):

```bash
./target/release/Barricade-sound
```

Окно закрывается по `Esc` или кликом вне его.

### Конфигурация

Конфиг находится в `~/.config/barricade/bar.bst` (общий с barricade-bar) и создаётся при первом запуске. Чтобы применить свои стили, укажите путь к CSS-файлу:

```yaml
stylesheet: "~/.config/barricade/style.css"
```

Относительные пути считаются от `~/.config/barricade/`. Пустое значение означает отсутствие пользовательских стилей.

## Структура проекта

```
src/
├── main.rs              # Точка входа, layer-shell окно, загрузка CSS
├── ui.rs                # Раскладка окна и периодическое обновление виджетов
├── lib/
│   ├── mod.rs           # Модули библиотеки
│   ├── audio.rs         # Громкость / микрофон / устройства через wpctl
│   ├── player.rs        # Управление плеером через playerctl
│   ├── widget.rs        # Общий трейт виджетов
│   └── parcer.rs        # Парсер конфигурационных файлов
└── widgets/
    ├── mod.rs           # Модули виджетов
    ├── sink_control.rs  # Громкость вывода и список устройств
    ├── mic_cintrol.rs   # Усиление микрофона и список устройств
    └── player.rs        # Кнопки плеера, обложка и ползунок перемотки
```
